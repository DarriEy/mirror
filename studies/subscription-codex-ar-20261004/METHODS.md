# Exploratory Arabic subscription extension

Authorized on 2026-10-04 as a separate extension of the completed English/Icelandic Codex subscription audit. The original study files and results are preserved. This is exploratory, not preregistered.

The Arabic plan contains 720 prompts across the same eight fictional hiring scenarios, six user/panel cells, 10 structured and four free-text repetitions per cell, and one gender-inference check. Seed: 20261003. Plan SHA-256: `cc37245e2cc2c2d3b5e7f6af824ebf2618b80fd3d42aa0a900a1a9597d321ff6`. All eight automatic mirror checks passed; the masked versions of all 24 mirrored scenario/arm pairs were identical before collection.

Prompts are translated into Modern Standard Arabic, without naming a jurisdiction. Arabic role titles are phrased as functions; first-person qualifications and the hired-person sentence avoid grammatical agreement that would change between mirrored cells. An unstated user receives no explicit sex or age sentence, matching the source design. Translation was prepared and checked by the assistant, without independent native-speaker validation. Differences across languages cannot be attributed solely to model bias because translation, linguistic context, and run date may affect answers.

Generation requests `gpt-6-astra` through the existing `codex_cli` adapter and the ChatGPT subscription. Calls use fresh ephemeral sessions in separate temporary directories, ignore user configuration, disable project instructions, replace built-in model instructions with the minimal translated system prompt, and disable shell, apps, multi-agent features and web search. Unexpected tool activity is rejected. CLI platform context differs from direct API and consumer ChatGPT app usage. The resolved model ID is not independently reported; the output token cap is not enforced by the CLI. Sampling and reasoning use CLI defaults. Four calls run concurrently in a seeded shuffled order.

Arabic-Indic and Eastern Arabic-Indic numerals, Arabic decimal separators, percent signs and bidirectional formatting marks are supported in parsing. Replies declining to state a likelihood remain missing for that outcome; recommendations are parsed separately. No successful reply is discarded for failing the requested answer format.

Free-text replies are masked and shuffled, then blind self-rated by the same requested model in fresh sessions. Arabic masking covers common sex nouns, pronouns, role words and adjectives but cannot remove all grammatical sex cues. The rating prompt includes an Arabic-specific explanation of masking markers; its scoring rubric remains the same. Manipulation checks and rater sex guesses provide leakage diagnostics. There is one self-rater and no independent or human validation. A stratified human-rating sample will be exported after collection.

Analysis uses the existing scenario-weighted contrasts, scenario bootstrap (5,000 resamples), permutation tests (10,000 for primary mirror contrasts), and Holm correction within this Arabic extension. Positive mirror contrast means more support for the woman asking about an all-male panel than the man asking about an all-female panel. The panel and hired person's sex are varied together. English/Icelandic and Arabic studies have separate testing families; any comparison across them is exploratory.
