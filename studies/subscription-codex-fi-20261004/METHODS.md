# Exploratory Finnish subscription extension

Authorized on 2026-10-04. This is a separate Finnish extension; earlier studies and their data are preserved. It is exploratory and was selected after observing the English, Icelandic and Arabic results.

Before collection, the prediction is that the recommendation contrast retains its positive sign, possibly with a different magnitude. No confident prediction of absence is made. Absence of a meaningful recommendation gap will be assessed using the existing equivalence criterion: the scenario-bootstrap 90% interval must lie wholly within -0.10 to +0.10. A nonsignificant test alone does not establish absence. This prediction is recorded locally, not externally preregistered.

The plan contains 720 prompts: eight scenarios, six cells, 10 structured and four free-text replies per cell, and one gender-inference check. Seed 20261003. Plan SHA-256: `c4e366aa157529fb5c6519e36054477a017e0b198126b651218f9b0cbc93cac6`. All eight automatic mirror checks and all 24 masked mirrored scenario/arm checks passed before collection.

The scenarios are translated into Finnish from the English source, preserving the facts and adding no jurisdiction. The generic pronoun hän is unchanged across panel/hired-person sexes. Sex is explicitly indicated through user, hired-person and panel nouns. Translation was prepared and checked by the assistant, without independent native-speaker validation. Cross-language differences may reflect translation, linguistic context or run date; they cannot be attributed solely to grammatical gender.

Generation requests gpt-6-astra through the existing codex_cli adapter and ChatGPT subscription. Each call uses a fresh ephemeral session in a temporary directory, ignores user configuration and project instructions, replaces built-in model instructions with the scenario's minimal system prompt, and disables shell, apps, multi-agent features and web search. Unexpected tool activity is rejected. CLI platform context differs from direct API and consumer app usage. The event stream does not independently report the resolved model ID. The API output-token cap is not enforced; reasoning and sampling use CLI defaults. Four calls run concurrently in a seeded shuffled order.

Recommendations and likelihoods are parsed separately. Replies refusing numerical likelihoods remain missing for that outcome and are not discarded. Free-text replies are masked and shuffled, then blind self-rated by the same requested model in fresh sessions. Finnish masking covers common gender nouns, inflections and titles, but is imperfect. A Finnish-specific masking explanation is added to the otherwise unchanged scoring rubric. One self-rater is used; there is no independent or human validation. A stratified sample for human rating is exported after collection.

Analysis uses the existing scenario-weighted contrasts, 5,000 scenario-bootstrap resamples and 10,000 permutations for the primary mirror contrasts, with Holm correction within this extension. Positive mirror contrast means more encouragement for the woman asking about an all-male panel than the man asking about an all-female panel. The hired person's and panel's sex vary together. Cross-language comparisons remain exploratory and are outside this study's two-outcome testing family.
